
# E-commerce Website

## Project Description

This is a simple E-commerce website
developed using Python Flask, HTML and CSS.

## Technologies Used

- Python
- Flask
- HTML
- CSS
- Pytest
- GitHub

## Project Structure

python-app/
    templates/
        index.html
    static/
        style.css
    tests/
        test_app.py
    app.py
    requirements.txt
    README.md

## Installation

Install the required dependencies:

pip install -r requirements.txt

## Run Application

python app.py

Open your browser and visit:

http://127.0.0.1:5000

## Run Tests

pytest

## Deployment

The application can be deployed using
Render by connecting the GitHub repository.
